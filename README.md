# Jarvis Agent — v0.2

مساعد شخصي عامل بمنطق الـ **Agent Loop**: بياخد أوامرك، يقرر بنفسه هل
محتاج يستخدم أداة (بحث، حاسبة، ملفات، ذاكرة، جيميل)، ينفذها فعليًا،
ويرد عليك برد نهائي. ده الأساس اللي أي "AI Employee" أو "Jarvis" مبني
عليه — الفرق بين النسخة دي والنسخة النهائية هو **عدد الأدوات**
و**القنوات** (واتساب، سوشيال ميديا)، مش المنطق الأساسي.

## 1. المعمارية

```
jarvis_agent/
├── agent/
│   ├── config.py            # كل الإعدادات في مكان واحد
│   ├── memory.py             # الذاكرة الدائمة (SQLite)
│   ├── security.py            # فلتر تقني يمنع تخزين بيانات مالية حساسة
│   ├── tools.py                 # سجل مركزي لكل الأدوات
│   ├── core.py                   # قلب النظام: الـ Agent Loop
│   └── tools_impl/
│       ├── calculator.py           # حسابات آمنة (بدون eval)
│       ├── files.py                 # قراءة/كتابة ملفات (محصورة في workspace/)
│       ├── web.py                    # بحث في الإنترنت
│       ├── memory_tools.py            # حفظ/استرجاع حقائق (الموديل بيقرر بنفسه)
│       ├── gmail_tool.py               # تنظيف Gmail (بحث/أرشفة/حذف)
│       ├── system_control.py            # إغلاق الجهاز + طابعة
│       ├── office_tools.py               # Word / Excel / PowerPoint
│       ├── file_organizer.py              # فهرسة وتنظيم أي بارتشن
│       └── image_tools.py                  # تعديل صور (بديل Paint)
├── integrations/
│   └── telegram_bot.py         # واجهة تحكم عن طريق تليجرام
├── data/                # قاعدة بيانات الذاكرة + بيانات اعتماد جيميل (بتتعمل تلقائيًا)
├── workspace/            # مساحة الملفات الآمنة للوكيل (بتتعمل تلقائيًا)
├── cli.py                 # واجهة سطر الأوامر
├── Jarvis.bat              # تشغيل بدبل كليك على ويندوز (بعد التثبيت)
├── check_setup.py          # تشخيص جاهزية كل تكامل قبل التشغيل
├── INSTALL.md               # دليل تثبيت مفصّل خطوة بخطوة لجهاز جديد
├── BUILD_EXE.md              # إزاي تعمل .exe فعلي بـ PyInstaller
├── install.sh                # تثبيت أوتوماتيكي (Linux/Mac)
├── install.bat                # تثبيت أوتوماتيكي (ويندوز)
├── requirements-core.txt      # الأساسيات (لازم دايمًا)
├── requirements-gmail.txt      # اختياري: تفعيل جيميل
├── requirements-telegram.txt    # اختياري: تفعيل بوت تليجرام
└── .env.example
```

### ليه المعمارية دي بالذات؟

- **فصل الأدوات عن الحلقة (core.py)**: تقدر تضيف/تشيل أداة من غير ما
  تلمس منطق المحادثة خالص.
- **الذاكرة منفصلة عن الأدوات اللي بتستخدمها**: `memory.py` هو التخزين
  الخام، و`memory_tools.py` هو الواجهة اللي الموديل شايفها.
- **الأمان مبني من الأول**: الحاسبة بتستخدم `ast` مش `eval`، أدوات
  الملفات محصورة في مجلد واحد، وأدوات جيميل بتتطلب تأكيد قبل أي حذف
  جماعي. لما تضيف أدوات أقوى، افتكر تطبق نفس المبدأ: **صلاحيات محدودة
  بوضوح**.

## 2. التشغيل

المشروع مقسّم لملفات متطلبات منفصلة عشان تركّب اللي محتاجه بس:

```bash
cd jarvis_agent
python -m venv venv
source venv/bin/activate        # أو venv\Scripts\activate على ويندوز

# الأساسيات فقط - لازم دايمًا (أقل من 10 ميجا)
pip install -r requirements-core.txt

# ثبّت بس اللي محتاجه فعليًا من دول:
pip install -r requirements-gmail.txt      # (~15-20 ميجا)
pip install -r requirements-telegram.txt   # (~5 ميجا)
pip install -r requirements-office.txt     # (~20 ميجا) Word/Excel/PowerPoint
pip install -r requirements-files.txt      # (~1 ميجا) نقل ملفات لسلة المهملات
pip install -r requirements-images.txt     # (~10 ميجا) تعديل صور

# أو لو عايز كل حاجة دفعة واحدة (مساحة كافية):
# pip install -r requirements-all.txt

export ANTHROPIC_API_KEY="sk-ant-..."

# اختياري لكن مفيد جدًا: افحص جاهزية كل حاجة قبل ما تبدأ
python check_setup.py

python cli.py
```

### جدول المساحة التقريبي

| المكوّن | الحجم | ملاحظة |
|---|---|---|
| كود المشروع نفسه | 36 كيلوبايت | نصوص Python بس |
| `requirements-core` | ~10 ميجا | لازم دايمًا |
| `requirements-gmail` | ~20 ميجا | لو مش محتاج جيميل، سيبها |
| `requirements-telegram` | ~5 ميجا | لو مش محتاج بوت، سيبها |
| `requirements-office` | ~20 ميجا | Word/Excel/PowerPoint |
| `requirements-files` | ~1 ميجا | نقل ملفات لسلة المهملات بأمان |
| `requirements-images` | ~10 ميجا | تعديل الصور (بديل Paint) |

جرّب تقوله مثلاً:
- "احسبلي 45 في 12 زائد 8"
- "دور على آخر أخبار Claude Opus"
- "احفظ إن اسمي فلان وإني بحب التفاصيل الكاملة في الردود"
- في محادثة جاية: "إيه اسمي؟" — هيرجعلك من الذاكرة الدائمة

## 3. التكاملات الحالية

### أ) تنظيف Gmail (`agent/tools_impl/gmail_tool.py`)

**الإعداد (مرة واحدة):**
1. https://console.cloud.google.com/ → مشروع جديد → فعّل "Gmail API"
2. "OAuth consent screen" → External → ضيف إيميلك في Test users
3. "Credentials" → "OAuth client ID" → نوع "Desktop app" → نزّل الملف
4. سمّي الملف `credentials.json` وحطه في `data/credentials.json`
5. أول تشغيل هيفتح المتصفح تسجل دخول مرة واحدة، وبعدها التوكن بيتخزن

**أمثلة استخدام (تقولها للوكيل بالعربي عادي):**
- "دور على كل رسايل العروض اللي أقدم من شهر"
- "نضّفلي الإيميل من رسايل category:promotions القديمة" (هيسألك تأكيد الأول)
- "احذف الإيميل ده" (بيروح للمهملات، مش حذف نهائي)

### ب) بوت تليجرام (`integrations/telegram_bot.py`)

**الإعداد:**
1. كلّم `@BotFather` في تليجرام → `/newbot` → هيديك TOKEN
2. ابعت أي رسالة للبوت بتاعك، وافتح:
   `https://api.telegram.org/bot<TOKEN>/getUpdates` عشان تلاقي `chat_id` بتاعك
3. ```bash
   export TELEGRAM_BOT_TOKEN="..."
   export TELEGRAM_ALLOWED_CHAT_ID="..."
   export ANTHROPIC_API_KEY="..."
   python integrations/telegram_bot.py
   ```

⚠️ **لازم تحدد `TELEGRAM_ALLOWED_CHAT_ID`** وإلا أي حد يلاقي البوت هيقدر
يتحكم في إيميلك وملفاتك.

### ج) التحكم في النظام (`agent/tools_impl/system_control.py`)

مفيش متطلبات إضافية على Linux/Mac. على ويندوز تأكد إن PowerShell متاح
(افتراضيًا موجود).

- **إغلاق الجهاز**: "اقفل الجهاز" - هيسألك تأكيد صريح قبل التنفيذ
  (محمي على مستوى الكود، مش بس التعليمات - راجع الاختبار في تعليقات الكود)
- **الطابعة**: "إيه الطابعات المتاحة؟" / "خلي كذا هي الافتراضية" / "اطبعلي الملف ده"

⚠️ **حد حقيقي**: تنصيب طابعة جديدة من الصفر (تعريفات/drivers) مش حاجة
قابلة للبرمجة بشكل عام - مرتبط بالهاردوير نفسه ولازم يتعمل من إعدادات
النظام يدويًا مرة واحدة. اللي بيشتغل هنا هو اكتشاف والتحكم في الطابعات
**المُعرّفة بالفعل**.

### د) حزمة الأوفيس (`agent/tools_impl/office_tools.py`)

```bash
pip install -r requirements-office.txt
```

- **Word**: "اعملي تقرير Word عن كذا" / "ضيف عنوان فرعي في المستند ده"
- **Excel**: "اعملي جدول Excel بالبيانات دي" / "ضيف معادلة SUM في الخلية كذا"
- **PowerPoint**: "اعملي عرض تقديمي من 5 شرايح عن كذا"

كل الملفات دي بتتحفظ جوه `workspace/` (نفس مبدأ أدوات الملفات العادية).

### هـ) تنظيم وفهرسة الملفات (`agent/tools_impl/file_organizer.py`)

```bash
pip install -r requirements-files.txt
```

**⚠️ الفرق المهم عن أدوات الملفات العادية**: دي أدوات بتوصل لأي مسار
على أي بارتشن، مش محصورة في `workspace/`، لأن الفهرسة والتنظيم معناهم
بالضرورة كسر حدود المساحة الآمنة.

- **الفهرسة**: "افهرسلي الـ D drive" / "دور على كل ملفات PDF أكبر من 10 ميجا"
- **التنظيم**: "نظّم مجلد التنزيلات" - بيعرضلك خطة الأول (dry_run) قبل أي تنفيذ فعلي
- **الحذف**: مفيش حذف نهائي خالص - أقصى حاجة `move_to_trash` بتنقل
  لسلة مهملات النظام (قابلة للاسترجاع)

### و) تعديل الصور (`agent/tools_impl/image_tools.py`)

```bash
pip install -r requirements-images.txt
```

**بديل Pillow بدل Paint** - "قص/كبّر/دوّر/حوّل الصورة دي" / "ضيف نص عليها" / "حوّلها لـ grayscale"

⚠️ **ليه مش Paint نفسه؟** برنامج mspaint.exe مالوش أي واجهة برمجية
(API) - الطريقة الوحيدة "للتحكم" فيه هي محاكاة حركة الماوس (GUI
automation)، وده هش وغير موثوق. Pillow بتدّي نفس النتائج (وأكتر)
بدقة رياضية وسرعة أعلى بكتير.

## 4. مؤجل بقرارك

- **الصوت وتتبع النشاط**: اتشالوا من المشروع بناءً على طلبك لتوفير
  المساحة. لو حبيت ترجعهم في أي وقت، قولي وهنضيفهم من تاني.
- **WhatsApp**: مؤجل - محتاج تقرر المسار (مكتبة غير رسمية بخطر حظر،
  ولا WhatsApp Business API الرسمي)
- **Facebook / Instagram**: محتاج Meta Business App + مراجعة (App Review)
- **X (تويتر)**: محتاج اشتراك مدفوع للكتابة (~200$/شهر) - مؤجل حاليًا

## 5. حظر المعاملات المالية (قرار دائم)

الوكيل ده **ممنوع تمامًا** من التعامل مع أي شيء مالي، على مستويين:

1. **مستوى القرار (`agent/config.py`)**: تعليمات صريحة وغير قابلة
   للتفاوض في الـ system prompt تمنع الوكيل من تنفيذ أو المساعدة في أي
   معاملة مالية (تحويلات، مدفوعات، شراء، وصول لحسابات بنكية أو محافظ
   رقمية)، حتى لو طلب المستخدم ذلك صراحة.

2. **مستوى تقني فعلي (`agent/security.py`)**: فلتر بيفحص أي محاولة
   حفظ في الذاكرة الدائمة، وبيرفض تخزين أي بيانات تشبه أرقام بطاقات،
   كلمات سر، أرقام حسابات بنكية، أو رموز تحقق (OTP) - **بغض النظر عن
   قرار الموديل نفسه**.

النظام مفيهوش أي أداة دفع أو تحويل من الأساس، فالحظر ده احترازي
ومستقبلي: أي حد يحاول يضيف أداة مالية للمشروع ده لازم يراجع القرار
ده الأول.

## 6. ملاحظة أمان عامة

كل ما تضيف أدوات أقوى (تنفيذ أوامر، وصول لحسابات حقيقية)، فكّر دايمًا:
"لو حد حط تعليمات خبيثة في نص بيقرأه الوكيل (إيميل، صفحة ويب)، إيه
أسوأ حاجة ممكن تحصل؟". حط حدود واضحة (whitelists، تأكيد يدوي للعمليات
الحساسة) بدل ما تدي صلاحية كاملة من الأول.
